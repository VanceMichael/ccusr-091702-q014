# 沉浸演艺合规控制台

本服务用于演出版本、双轨审查、现场降级和调查裁决。仓库提供可启动的健康检查、SQLite 迁移入口和最小测试，领域功能将在这些约定上持续建设。

## 领域资料

核心记录包括：演出版本、场次、内容意见、安全意见、放行单、降级方案、红线事件、调查案。

内容与安全分别通过后才可放行；降级只能选预批方案；红线事件冻结关联版本；调查决定以追加方式保留历史。

## 本地命令

执行 ./scripts/migrate 可重复应用数据库迁移；执行 ./scripts/test 运行自动化测试；执行 ./scripts/start 启动 HTTP 服务。数据库默认写入 data/show_compliance.sqlite3，也可通过 DATABASE_PATH 指定其他路径；监听地址由 HOST 和 PORT 配置。

Docker 镜像构建后使用相同的迁移与启动入口，运行期间不需要外部数据库、缓存或消息服务。
